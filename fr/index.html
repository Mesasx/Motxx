Nous hébergeons les flux n8n sur des serveurs européens (VPS Hetzner, Allemagne), dans le respect du RGPD. Nous n'envoyons pas d'informations sensibles hors de l'Union européenne, sauf si une API spécifique l'exige, et toujours avec consentement préalable.
